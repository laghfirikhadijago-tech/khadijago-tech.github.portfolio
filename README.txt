KHADIJA LAGHFIRI — PORTFOLIO WEBSITE

1. Open index.html in a browser to preview the website.
2. Before publishing, replace the GitHub link in the Contact section with your exact profile URL.
3. Check that the project descriptions match what you want to show publicly.
4. Publish the files using GitHub Pages:
   - Create a GitHub repository named: yourusername.github.io
   - Upload index.html (and this README if you want).
   - In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
   - Your site address will be https://yourusername.github.io

This is a starter portfolio. No email or personal contact details have been invented.
